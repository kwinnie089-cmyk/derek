UPDATING THE WEBSITE
Update index.html for page structure, portfolio-content.js for gallery photos and
package details, portfolio-theme.css for styling, or portfolio-navigation.js for
navigation. Upload changed files and new optimized images to the same paths in the
public repository and commit the update to main. GitHub Pages will publish the
update automatically.

GitHub Pages is a static website host. It does not provide a secure admin dashboard
or store booking submissions. Do not put passwords or private keys in this folder.
